## ✨ What is Alchemiroll?

Alchemiroll is a fully-functional, browser-based dice game based on the classic rules of Yahtzee, reimagined with an immersive alchemical theme. Instead of plain dice, you'll cast magical runes. Your scorecard is a grimoire where you record your findings, from "Basic Ingredients" to "Complex Concoctions." The goal remains the same: score as high as you can by rolling for specific combinations over 13 rounds.

This project was built to showcase modern frontend development techniques within a fun, interactive, and visually polished application.

## 🔮 Key Features

-   **Classic Yahtzee Logic**: All the rules you know and love, including 3-of-a-kind, straights, full house, and the coveted 5-of-a-kind (The Philosopher's Stone!).
-   **Immersive Theming**: A unique alchemical aesthetic, from the "rune" dice and parchment-style "grimoire" scorecard to the thematic naming of score categories.
-   **Interactive UI**: Smooth animations for dice rolls, satisfying visual feedback for holding dice, and glowing potential scores to guide your choices.
-   **Dynamic Scorecard**: Automatically calculates and displays potential scores for your current roll, making strategic decisions easier.
-   **Responsive Design**: A clean, mobile-friendly layout that looks great on any screen size.
-   **Built with Modern Tech**: Crafted with React, TypeScript, and Tailwind CSS for a robust and maintainable codebase.

## 🛠️ Tech Stack

-   **UI Framework**: [React](https://reactjs.org/)
-   **Language**: [TypeScript](https://www.typescriptlang.org/)
-   **Styling**: [Tailwind CSS](https://tailwindcss.com/)

## 🎲 How to Play

1.  **Goal**: Achieve the highest "Final Elixir" potency (total score) after 13 rounds.
2.  **Casting Runes**: Each round, you get up to **three** casts. Click `Cast Runes` to roll.
3.  **Holding Runes**: After a roll, click on any rune to "hold" it. Held runes won't be re-rolled on your next cast.
4.  **Recording Findings**: After your first, second, or third cast, you **must** select an empty category in your Grimoire (scorecard). Your potential scores will glow to help you decide.
5.  **Complete the Grimoire**: The game ends when all 13 categories on the scorecard are filled. Plan your moves carefully to maximize your score!

### Scoring Highlights:
-   **Purity Bonus**: Score 63+ in the upper section ("Basic Ingredients") for a **35 point bonus**.
-   **The Philosopher's Stone**: Rolling five of the same rune scores **50 points**.
-   **Philosopher's Bonus**: Each additional five-of-a-kind after the first earns a **100 point bonus**!

## 🚀 Getting Started

This project is set up to run directly in the browser with no build step required.

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/mahmudnibir/alchemiroll.git
    ```

2.  **Navigate to the directory:**
    ```bash
    cd alchemiroll
    ```

3.  **Open the `index.html` file:**
    -   Simply open the `index.html` file in your favorite web browser (like Chrome, Firefox, or Safari).

That's it! The alchemical experiment can now begin.
